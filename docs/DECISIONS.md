# AI Council — архитектурные решения (19.10.2026)

## Согласованные требования

- Самостоятельный браузерный чат с OpenAI и Gemini; адаптеры моделей взаимозаменяемы.
- Независимый параллельный первый этап: модели не получают текущий ответ партнёра.
- Второй этап: перекрёстная критика обоих первоначальных ответов.
- Третий этап: аргументированный ответ на критику, без принудительного консенсуса.
- Барьер синхронизации между этапами: следующий этап не начинается, пока не завершены оба ответа текущего.
- Не использовать короткий фиксированный таймаут для завершения долгого запроса.
- Индивидуальная настройка модели и глубины размышления в интерфейсе; отдельные обращения к одной модели.
- Вторая форма общения — свободная беседа, без обязательного итогового протокола.
- Долговременная память и проектные пространства планируются; пока хранится история комнат и ограниченный контекст.
- Лицензия собственных компонентов MIT; предпочтение MIT/Apache-2.0/BSD для внешних компонентов.

## Реализация MVP

FastAPI + asyncio + SQLite + веб-интерфейс. Оркестратор пока собственный; Microsoft Agent Framework — рассматриваемый кандидат, **не подключён**. Первый режим выполняет шесть ответов моделей и отдельный седьмой запрос для итогового редакционного протокола. Режим свободной беседы выполняет два открытия и ограниченное число поочерёдных дополнительных реплик.

Прототип поддерживает локальный демонстрационный режим без ключей. Девять автономных тестов проходят. Реальные OpenAI/Gemini API в данной сборке не проверены; наличие SDK-интеграции не равно успешному реальному запуску.

## Границы версии

Пока отсутствуют авторизация, TLS, полноценное разграничение проектов, вложенные документы, интеллектуальная проектная память, прозрачный учёт расходов, стриминг токенов, голосовой режим и гарантированное мгновенное прерывание активного SDK-запроса. Текущий интерфейс получает события периодическим опросом, а не постоянным потоком.

Использовать только на 127.0.0.1. API-ключи хранить в локальном .env; никогда не коммитить. Медицинские и другие чувствительные персональные данные не загружать в этот прототип. Подписка ChatGPT не оплачивает обращения к API.

## Технические риски

Настройки уровня размышления зависят от версии модели; несовместимые параметры могут вызвать ошибку API. Не обещать доступ к приватным скрытым рассуждениям моделей. При повторе неуспешного сетевого вызова возможна повторная тарификация. Перед удалённым развёртыванием требуются аутентификация, TLS, лимиты и отдельная проверка безопасности.
