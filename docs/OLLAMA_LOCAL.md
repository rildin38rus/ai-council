# AI Council: Gemini API + локальная модель Ollama

**Цель:** проводить настоящие 3 синхронизированных раунда двумя независимыми моделями **без OpenAI API-биллинга**. При этом первая модель — **локальная Ollama**, а не ChatGPT/OpenAI. Проверка API-ключа и чтение OpenAI `/v1/models` не гарантируют оплачиваемую генерацию. Ошибка `HTTP 429` при нулевом балансе — основание использовать этот маршрут.

## Запуск на Windows 10/11

1. Установите Ollama с [официального сайта](https://ollama.com/download/windows). Приложение должно быть запущено **на том же компьютере, где AI Council**. Стандартный локальный адрес: `http://127.0.0.1:11434`.
2. В PowerShell запустите `ollama pull qwen3:4b-instruct` и дождитесь завершения загрузки (примерно **2.5 ГБ модельных файлов**; дополнительные ресурсы памяти зависят от платформы). Для слабого ПК можно выбрать `qwen3:1.7b`; для более мощного — `qwen3:8b`. Какая модель лучше — проверим на реальных задачах.
3. Проверьте, что модель установлена: `ollama list`. Альтернативная API-проверка: `Invoke-RestMethod http://127.0.0.1:11434/api/tags`.
4. Скачайте/обновите исходники AI Council из `main`. Запустите `start_windows.bat` для создания `.env` (или создайте `.env` из `.env.example` вручную), после чего **остановите сервер**.
5. В локальном `.env` укажите:

   ```ini
   COUNCIL_DEMO=0
   COUNCIL_PRIMARY_PROVIDER=ollama
   OPENAI_API_KEY=
   GEMINI_API_KEY=ваш_ключ_Gemini_API
   ```

   **Никогда не отправляйте ключ в чат и не добавляйте `.env` в публичный GitHub.** Ключ в GitHub Actions Secrets для PR-ревьюера не передаётся автоматически локальному приложению.
6. Запустите `start_windows.bat` повторно. В браузере перейдите по адресу `http://127.0.0.1:8000`. Слева должна появиться **«Локальная модель (Ollama)»**, справа — **Gemini**.
7. Нажмите «↻ Обновить модели»: появятся реально установленные локальные модели (из Ollama `/api/tags`), а рядом — каталог Gemini при наличии локального ключа. Выберите `qwen3:4b-instruct` и доступную Gemini-модель, например `gemini-3.5-flash-lite` или `gemini-3.8-flash` **только если API действительно её разрешает**.
8. Первый вопрос для теста: «Назовите три риска автоматической обработки лабораторных отчётов и предложите способы проверки». В режиме «Совместное обсуждение · 3 этапа» ожидаются **6 сообщений и отдельный итоговый протокол** (ещё один локальный вызов Ollama).

## Важные особенности

- Внешних OpenAI-запросов в режиме `COUNCIL_PRIMARY_PROVIDER=ollama` **не требуется**. Локальный сервер доступен только на loopback. **Второй участник Gemini всё равно отправляет тексты запросов и ответы обеих сторон в Google**, в том числе во втором и третьем раундах. Не используйте этот режим для конфиденциальных медданных без подходящих условий обработки.
- Отсутствие Ollama, неправильное имя модели или недостаток оперативной памяти приведут к ошибке отдельного этапа: уже сохранённые ответы других этапов сохраняются. Для повторного запуска используйте «Возобновить».
- Истории старых комнат с OpenAI остаются в базе SQLite; новые локальные сообщения сохраняются под агентом `local`, не маскируются под `openai`.
- `GET /api/models` показывает каталог Ollama в поле `ollama`, а текущий режим — `GET /api/config` в `primary_agent`. Доступность Gemini-модели в списке не гарантирует платные квоты и успешную генерацию.
- Скрипт не устанавливает Ollama автоматически, не загружает модели без разрешения пользователя и не создаёт платных подписок.
- Обновление `.env` требует перезапуска AI Council. Для возврата к OpenAI установите `COUNCIL_PRIMARY_PROVIDER=openai` и предоставьте отдельный рабочий OpenAI API-баланс.

## Технические контракты

- Ollama: `GET http://127.0.0.1:11434/api/tags` и `POST http://127.0.0.1:11434/api/chat`.
- JSON: `model`, `messages`, `stream: false`, `think: false`, `options.num_predict: 1536`.
- API Ollama не использует ключей и является локальным; нельзя открывать его на публичный интерфейс без отдельной аутентификации.
- Официальные справочники: https://docs.ollama.com/api ; https://ollama.com/library/qwen3:4b-instruct .

## Статус проверки

GitHub Actions проверяет работу на заглушках без реальных ключей и без скачивания многогигабайтной модели. Реальный запуск Ollama на компьютере пользователя и успешные генерации Gemini должны быть проверены отдельно; **офлайн CI не доказывает готовности реального API**.
