# AI Council — автоматическое ревью Pull Request через Gemini

**Статус:** проверено офлайн (20 тестов), **реальный Gemini API пока не вызывался**. Скрипт не исполняет код PR и не предоставляет модели средства изменения репозитория.

## Настройка

1. Откройте https://github.com/rildin38rus/ai-council/settings/secrets/actions → **New repository secret**.
2. Имя секрета: `GEMINI_API_KEY`. Значение — **только ваш личный API-ключ Gemini**. Не присылайте его в чат, Issue или PR.
3. Убедитесь, что для репозитория включены GitHub Actions. Workflow запрашивает ограниченное разрешение `pull-requests: write` для комментария, а `contents: read` — для чтения.
4. После появления workflow в `main` создайте новый PR из ветки этого же репозитория **от владельца**. Gemini проверит diff и напишет комментарий.
5. Для ручного запуска: **Actions → Gemini PR review → Run workflow**, укажите номер PR. Повторный запрос для уже проверенного SHA пропускается, если бот успел опубликовать комментарий.

По умолчанию: `gemini-3.5-flash-lite`, `thinkingLevel=medium`. Переменные GitHub Actions: `GEMINI_REVIEW_MODEL` и `GEMINI_REVIEW_THINKING_LEVEL` (`minimal`, `low`, `medium`, `high`). Для старых моделей Gemini 2.5 код по-прежнему поддерживает отдельный `GEMINI_REVIEW_THINKING_BUDGET`, но **не следует** задавать вместе уровень и бюджет; workflow по умолчанию настроен на семейство 3.x. Наличие модели в документации не гарантирует доступность для конкретного проекта: после HTTP 404 проверьте список доступных моделей для своего ключа.

## Безопасность и ограничения

- Запускается только для PR **от владельца репозитория** с веткой **этого же репозитория**. PR из форков автоматически пропускаются.
- Используется `pull_request`, **не** `pull_request_target`; checkout всегда указывает на доверенную ветку `main`. Код из PR **не выполняется** и не устанавливается.
- Модели передаётся только текст diff GitHub API как **недоверенные данные**, максимум 30 файлов или около 42 000 символов; пропуски и обрезки отмечаются в отчёте.
- Маскирование распространённых шаблонов секретов — лишь частичная защита, **не полноценный DLP**. Не загружайте в PR ключи, медицинские данные и персональные сведения.
- Результат Gemini — публичный комментарий к PR. Модель может ошибаться и не заменяет обычные тесты и решение человека.
- Реальный API платный и не включён в подписку ChatGPT. Идемпотентность по SHA уменьшает повторные расходы, но сетевые сбои и гонки не гарантируют строго однократную тарификацию.
- При отсутствии `GEMINI_API_KEY` workflow **завершится с ошибкой** и не опубликует выдуманный отчёт.
- Первая PR-сборка, которая добавляет сам workflow, может ещё не пройти ревью Gemini: для надёжной проверки нужно, чтобы скрипт уже был в доверенной ветке `main`.

## Что получим

Новый PR → GitHub Actions автоматически собирает его diff → Gemini API проверяет изменения → публикует замечания с приоритетами P0/P1/P2 → ChatGPT читает замечания в GitHub и готовит следующий патч. Это первый автоматический мост к Gemini, **ещё не двусторонний чат**.
