# AI Council — «Одна комната на троих»

**Рабочий локальный прототип (Ollama + Gemini)** от 19.10.2026. Исходный код открыт под MIT (см. `LICENSE`). 2 агента, 3 синхронизированных этапа, режим свободной беседы и режим прямого обращения, SQLite-история, сохранение успешных ответов перед повторами, кнопки «Остановить» и «Возобновить», настройки моделей и глубины рассуждений, итоговый протокол и экспорт Markdown. Есть **демо без ключей**.

## Без OpenAI API: Ollama + Gemini

При отсутствии оплаченного OpenAI API можно использовать локальную модель **Ollama** как первого агента, а **Gemini API** — как второго. Локальный агент **не является ChatGPT** и явно подписан `local` в базе/интерфейсе.

**Windows:** установите [Ollama](https://ollama.com/download/windows), выполните `ollama pull qwen3:4b`, затем в локальном `.env` выставьте `COUNCIL_DEMO=0`, `COUNCIL_PRIMARY_PROVIDER=ollama`, `GEMINI_API_KEY=...`. Запустите `start_windows.bat`. OpenAI-ключ не нужен. Полное руководство: [docs/OLLAMA_LOCAL.md](docs/OLLAMA_LOCAL.md).

**Ограничение:** пользователь должен самостоятельно установить Ollama и загрузить модель. Автотесты не проверяют реальную доступность Ollama на пользовательском ПК и фактическую квоту Gemini API.

## Быстрый запуск в Windows

Требуется Python 3.11+ и интернет для первоначальной установки пакетов.

1. Распакуйте ZIP в отдельную папку и запустите `start_windows.bat`.
2. Дождитесь адреса `http://127.0.0.1:8000` в консоли, откройте его в браузере.
3. Задайте любой вопрос. По умолчанию включена **симуляция**, не настоящие ИИ-модели.
4. Для настоящих моделей закройте сервер. В файле `.env` укажите `COUNCIL_DEMO=0`, заполните `OPENAI_API_KEY` и `GEMINI_API_KEY`, затем запустите `start_windows.bat` повторно. Убедитесь, что ваши API-аккаунты имеют доступ к выбранным моделям. Для проверки сначала можно выбрать доступные недорогие модели.

## Запуск на Linux / macOS

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Для Windows PowerShell можно использовать `start_windows.bat` или создать виртуальное окружение вручную. Секреты не вставляйте в интерфейс чата — только в `.env` и только на сервере.

## Выбор моделей через API

В версии 0.2.2 добавлен `GET /api/models`: приложение запрашивает список доступных ID у OpenAI и Gemini с помощью ключей, указанных **локально на сервере** (кэш 5 минут). В браузере появятся подсказки выбора модели и кнопка «↻ Обновить модели». Каталог не расходует токены генерации и не гарантирует доступность отдельных моделей по тарифу. Описание четырёх семейств на скриншоте, рекомендуемые задачи, настройки мышления и ориентировочные цены — в [docs/MODEL_ROUTING.md](docs/MODEL_ROUTING.md). Gemini 4 Argon / 3.1 Pro требуют платного API; наличие в приложении Gemini не означает доступ через Free API.

## Архитектура

`app.py` — FastAPI; `council/engine.py` — независимые ответы + барьеры + контекст; `council/providers.py` — взаимозаменяемые адаптеры; `council/store.py` — SQLite-история и восстановление; `static/index.html` — автономный браузерный UI.

Два API-запроса на каждом этапе выполняются одновременно. Этап 2 стартует только после *двух* ответов этапа 1; этап 3 — только после *двух* комментариев этапа 2. Если OpenAI завершил раньше, его ответ сразу записывается и показывается. При сбое успешные результаты сохраняются, а «Возобновить» вызывает только ещё отсутствующие ответы. За раз выполняется 6 запросов для трёх раундов и ещё 1 отдельный запрос к OpenAI для редакционного итогового протокола — **7 API-запросов**. Протокол не считается четвёртым раундом и не является гарантией проверки фактов. При сбое резюме шесть готовых ответов не запрашиваются повторно.

В режиме прямого обращения выполняется 1 запрос. В «Свободной беседе» обе модели сначала независимо отвечают на тему, затем по очереди обмениваются 2–8 дополнительными репликами (начинает OpenAI): всего 4–10 вызовов. Начальные ответы не видны друг другу до завершения обоих. Настройка количества реплик не даёт моделям бесконтрольно разговаривать и расходовать бюджет. После завершения можно задать следующий вопрос в той же комнате. Настройки каждой модели фиксируются в момент создания обсуждения. Прошлый завершённый контекст комнаты (не более 4 вопросов) может передаваться обоим агентам; этим объясняется, как поддерживается общий контекст между обсуждениями, но личная память привычных приложений ChatGPT/Gemini автоматически не доступна.

## Ограничения безопасности

**Локальный прототип; не открывать порт в интернет.** Нет логина, разграничения доступа, HTTPS и изоляции пользователей. История хранится без шифрования в SQLite на диске. При работе с медицинскими/финансовыми данными необходимо отдельно реализовать управление доступом, редактирование чувствительных сведений, резервные копии и политику обработки данных. Не используйте реальные данные пациентов в текущей версии.

## Изменения версии 0.2.0

- Новый режим «Свободная беседа» с лимитом 2/4/6/8 ответных реплик и синхронным открытием темы.
- Настоящий итоговый протокол на основании шестёрки ответов; редактор — OpenAI, результат отдельно сохраняется в БД и показывается на экране. Не путать с независимым арбитром.
- Обновление старой SQLite-истории без удаления данных.
- Поддержка `max` для OpenAI, если выбранная модель и аккаунт это позволяют.
- Запрет на запуск ещё одной задачи в той же комнате, пока предыдущая не завершена.
- `store=False` в запросах OpenAI, чтобы не создавать серверно хранимую цепочку Responses; политика Google API регулируется отдельно.

### Проверка с живыми API

Настройки моделей по умолчанию являются *вариантами*, а не гарантией доступа. При ошибке прав доступа, квот или неподдерживаемого уровня рассуждений выберите доступную в вашем API-аккаунте модель и повторите запрос. При повторе сохраняются успешные ответы. Для начала используйте короткий вопрос и режим с низким усилием: каждый раунд платный. **Подписка ChatGPT Plus не оплачивает API автоматически.**

Не обещаем успешное соединение с настоящими API до ввода реальных ключей и тестирования. Не публикуйте `.env` или файлы SQLite. При редактировании `.env` сервер необходимо перезапустить.

### Сотрудничество с Gemini

`docs/GEMINI_HANDOFF.md` — независимое задание для Gemini (аудит, тесты, анализ Gemini API, интерфейс). `docs/WORK_PLAN.md` — зоны ответственности, тесты приёмки, этапы и риски. Вторая модель пока не подключена к этому чату напрямую: поручение Gemini нужно передать вручную один раз, до появления полноценного моста.
